# task-manager
Un gestionnaire de tâches simple en Python.

## 🚀 Installation

```bash
git clone https://github.com/VOTRE_USERNAME/task-manager.git
cd task-manager
```

## 📖 Utilisation

```python
from task_manager import TaskManager

manager = TaskManager()
manager.add_task("Ma première tâche", "Description optionnelle")
manager.display_all()
```

## 📁 Structure du projet

```
task-manager/
├── README.md
├── .gitignore
├── task.py          # Classe Task
├── task_manager.py  # Classe TaskManager
└── main.py          # Exemple d'utilisation
```

## ✨ Fonctionnalités

- ✅ Créer des tâches avec titre et description
- ✅ Marquer des tâches comme complétées
- ✅ Afficher les tâches en cours / complétées
